# API v2

Base path: `/api/v2`. The original `/`, `/define/{word}`, and new root routes remain available as additive compatibility aliases. Interactive OpenAPI is served at `/docs` and `/redoc`.

## Dictionary and relationships

| Method and route | Parameters | Behavior |
|---|---|---|
| `GET /define/{word}` | path word; optional `context` up to 500 characters | Full entry; retains flat `meanings` and `synonyms`; context reorders definitions using local token overlap without editing source text |
| `POST /define/batch` | JSON `{"words":[...]}` | Per-word success/error results; duplicates are safe; maximum size is `MAX_BATCH_SIZE` (default 50) |
| `GET /synonyms/{word}` | `limit` 1–100 | Merges dictionary and Datamuse synonyms |
| `GET /antonyms/{word}` | `limit` 1–100 | Merges dictionary and Datamuse antonyms |
| `GET /related/{word}` | `kind=associations\|semantic\|similar` or a documented Datamuse relation; `limit` 1–100 | Returns associations, semantic relationships, or similar meanings |
| `GET /graph/{word}` | `depth` 1–2; `limit` 1–100 nodes | Bounded graph assembled from synonym, antonym, trigger, and WordNet relationships |
| `GET /rhymes/{word}` | `limit` 1–100 | Uses Datamuse rhyme results |
| `GET /suggest/{word}` | `limit` 1–100 | Datamuse suggestions with optional local edit-distance fallback |

## Word intelligence and local corpus

| Method and route | Parameters | Behavior |
|---|---|---|
| `GET /search` | Exactly one of `prefix`, `pattern`, `anagram`, `length`; `limit` 1–100; `offset` 0–10000 | Corpus search when configured; Datamuse prefix/pattern search otherwise |
| `GET /anagrams/{word}` | `limit`, `offset` | Searches the optional local corpus |
| `GET /forms/{word}` | optional `part_of_speech` | Heuristic English lemma and word forms; not a full linguistic analyzer |
| `GET /frequency/{word}` | — | Frequency per million from a configured local corpus; a listed word without a score returns `null` |
| `GET /random` | — | Random entry from an optional local corpus |
| `GET /word-of-the-day` | — | Deterministic word for the current UTC date from a local corpus |
| `GET /health` | `check_providers=false` by default | Local application state; provider state is `not_checked` unless `true` triggers actual requests |

### Entry response

```json
{
  "word": "apple",
  "meanings": ["A fruit."],
  "synonyms": ["pome"],
  "phonetics": [{"text": "/ˈæp.əl/", "audio": null}],
  "meaning_details": [{
    "part_of_speech": "noun",
    "definitions": [{"definition": "A fruit.", "example": "I ate an apple."}]
  }],
  "antonyms": [],
  "related_words": [],
  "origins": [],
  "sources": ["dictionaryapi.dev", "datamuse"],
  "frequency_per_million": null
}
```

`meanings` remains a flat list for clients of the original endpoint. Structured detail is in `meaning_details`. Providers may omit any optional information; this API does not fill in unsupported data.

### Status codes

- `200`: successful lookup, including valid empty relationship/search results.
- `404`: dictionary word or requested corpus entry is not present.
- `413`: batch exceeds the configured maximum.
- `422`: invalid input or unsupported parameters.
- `503`: required provider or optional local corpus is unavailable.

Batch results are isolated per word; one failure does not fail the other entries. Datamuse failure does not prevent definition results where the dictionary provider succeeds.
