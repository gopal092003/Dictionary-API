# Changelog

## 2.0.0 — 2026-10-19

- Added resilient DictionaryAPI.dev and Datamuse adapters, normalized response models, and provider attribution.
- Added versioned API routes for relationships, suggestions, search, word forms, batch lookup, local corpus tools, and health reporting.
- Added memory and SQLite TTL caches, a reusable Python client, CLI, and SQLite vocabulary import/export.
- Added optional user-supplied offline dictionary and word corpus support.
- Added packaging, Docker, CI, documentation, and contribution guidance.
